# Communication Centre — Phase 2 historical note

This document has been superseded by the current production implementation described in [COMMUNICATION-CENTRE-SETUP.md](COMMUNICATION-CENTRE-SETUP.md) and [PHONEYA2-COMMUNICATION-SETUP.md](PHONEYA2-COMMUNICATION-SETUP.md).

Current campaign audiences are:
- Confirmed newsletter subscribers for promotional email campaigns.
- All active/approved registered partners for operational Partner Studio updates, including partners who never subscribed to the newsletter.

Customers who place orders receive transactional order confirmation and order-status email/SMS notifications. Buying does not automatically subscribe anyone to marketing. The current implementation uses Brevo, not Resend.

Do not follow any old instructions in this historical note that refer to Resend or an unmerged feature branch.
