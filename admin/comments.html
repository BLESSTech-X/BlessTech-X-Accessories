Community moderation

Blog Comment Review

New comments are stored privately with status: "pending". They do not appear to other visitors until you approve them. Use GitHub sign-in to review and change the status; this avoids putting a privileged approval token in public browser code.

Open pending comment files ↗Review comments on GitHub

Approve a comment

  1. Open a comment-…md file on the community-comments branch.
  2. Check the post, name and message. If suitable, change status: "pending" to status: "approved".
  3. Commit the change directly to community-comments. The approved comment can then appear publicly after the site refreshes its comment data.

Reject a comment

  1. Open the comment file and change the status to "rejected".
  2. Commit the change. Rejected comments stay out of the public comments feed.

If comment submission fails

The public form saves through a Cloudflare Pages Function, which writes a Markdown file to GitHub. If GitHub rejects that write, the site now returns a more specific safe error and records the GitHub status/message in Cloudflare function logs.

Do not put a GitHub token in this page or any public JavaScript. The secret must remain in Cloudflare Pages environment variables as GITHUB_COMMENTS_TOKEN, with permission to write contents to the repository and branch.
